03 The course

  1. One spec. A fully specified CLI program: JSON in, JSON out, deterministic, with a closed set of error codes.
  2. Five players. Python, JavaScript, Go, Rust and C. Each gets an independent agent session with tools, a shell and room to self-test.
  3. One referee. A language-agnostic conformance suite that only talks to the binary through its CLI. Fail it and your score doesn't count.
  4. The score. Session output tokens: everything the agent wrote, including reasoning, tool calls and rewrites.
Workflow engineDAG execution, $ref, conditions, retries, 40+ ops
Expression evaluatortokenizer, precedence parser, i64 math, exact error positions
JSON PatchRFC 6901 pointers, six ops, atomicity, error taxonomy

Model: {{model}}, thinking=high, one autonomous session per run. Every run counted here passes its scored suite.

04 The fine print

Passing ≠ correct

Every submission passes the scored fixtures, but a finite suite doesn't prove complete correctness. A review found two grader bugs, which have been fixed and rescored. No pass/fail result changed.

Not a frozen eval

Some specs, fixtures and oracles were corrected after submissions were examined. The Git history records every change, but this wasn't a pre-registered evaluation.

Trust, partially verified

The raw session logs aren't published, so usage totals and compliance with the no-peeking rules can't be audited from the repo. The launcher isn't an OS sandbox.

05 Contribute

Every submission and the full test suite are in the repo, so you can check these numbers without running a model.

Rescore the results

Rebuild every committed submission and rerun the test suite. No API key needed.

git clone {{repo}}
python3 benchmark/rescore.py

Add a test case

One JSON file per behaviour. It has to follow from the spec and pass against the reference implementation.

benchmark/holdout/<category>/your_case.json
python3 benchmark/runner.py --language oracle

Add a model or a language

A new round for another model, or an adapter for Kotlin, Swift, Zig and so on. Use a new round id and commit failed runs too.

benchmark/rounds/<round>/round.json
benchmark/adapters/<lang>.json
